About this data
  • Source: ilyankou/passport-index-dataset (passport-index-tidy.csv), the same file the Travel Desk visa checker loads.
  • Easy access = visa free + visa on arrival + ETA. A number in the CSV is a visa-free stay in days and is counted as visa free.
  • The data is built into this file, so it works offline. Refresh from GitHub loads the latest version while you're online. Nothing is saved; reopening the file shows the built-in snapshot again.
  • Co-visa benefits (e.g. a valid US/UK/Schengen visa unlocking entry elsewhere) and conditional rules aren't in this dataset and aren't shown here.
  • This is a community-maintained dataset and can lag policy changes. Always confirm with the embassy, IATA Timatic or the airline before booking.
